# Button

Montage 버튼 규격(크기 3단 × 색 4종)을 따르는 버튼이다.

| 크기 | 클래스 | 높이·모서리 | 글자 | 쓰는 곳 |
|---|---|---|---|---|
| medium | `.so-btn--md` | 40px · `--radius-12` | label1 600 | 패널의 주 동작 1개(전체 실행) |
| small | `.so-btn--sm` | 32px · `--radius-10` | caption1 600 | 단계 버튼, 확인창의 예/아니오 |
| xsmall | `.so-btn--xs` | 28px · `--radius-8` | caption1 600 | 패널 아래 보조 동작 |

- `--primary`(brand 채움): 되돌리기 어려운 동작(저장)과 패널의 주 동작. 한 화면에 1~2개.
- `--outlined`(흰 바탕, `--brand-text` 글자): 조회·점검 같은 읽기 동작.
- `--assistive`(회색): 취소, 진단 내용 복사.
- `--text`: 복사·내려받기 같은 가벼운 동작.
- 실행 중에는 같은 단계 버튼을 모두 `disabled`로 막고 누른 버튼에 `.so-spinner`를 붙인다.
- 라벨은 일어나는 일을 그대로 쓴다: "저장", "④ 점검", "진단 내용 복사". "확인" 같은 모호한 말은 피한다.
- 접근성: 흰 글자/`--brand` 대비가 3.5:1이라 라벨은 항상 600 굵기로 쓴다. 키보드 포커스는 `--shadow-focus`.
