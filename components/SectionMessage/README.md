# SectionMessage

패널 안에서 상태를 알리거나 확인을 받는 상자다. 브라우저 `alert`·`confirm` 대신 이것을 쓴다.

| 종류 | 클래스 | 아이콘 | 쓰는 때 |
|---|---|---|---|
| 안내·확인 | `--info` | i / ? | 시작 안내, **저장 전 확인**(되돌리기 어려운 동작은 반드시 여기서 한 번 더 묻는다) |
| 성공 | `--positive` | ✓ | 점검 이상 없음, 변경할 게 없음 |
| 주의 | `--caution` | ! | 화면 요소를 못 찾음 → "직접 처리 후 [계속]" + [중단] |
| 오류 | `--negative` | ! | 멈춘 이유 + "[진단 내용 복사]를 눌러 Claude에게 붙여넣어 주세요" |

- 제목(`.so-msg__title`)은 한 문장으로 무슨 일인지, 본문은 숫자나 다음 할 일.
- 버튼은 `.so-msg__actions` 안에 small 크기로. 예 = `primary`, 아니오 = `assistive`.
- 아이콘 점의 색은 상태색 채움, 글자는 `--fg-secondary`. 상태색(초록·주황·빨강)은 글자로 쓰지 않는다.
