# Checkbox

목록에서 처리할 행을 고를 때 쓰는 체크박스다. 기본값은 **해제**다. 사용자가 고른 것만 처리한다.

- `<input type="checkbox" class="so-checkbox">`. 20px, 모서리 `--radius-5`, 테두리 `--line`, 선택 시 `--brand` 채움 + 흰 체크.
- 표 첫 열에 둘 때 머리 행에 전체 선택 체크박스를 두고, 표 위 섹션 머리에 "일시품절만 · 전체 · 해제" 같은 빠른 선택 `text` 버튼을 둔다.
- 선택된 행은 `tr.is-selected`로 `--brand-subtle` 바탕을 깐다.
- 체크 결과가 무엇을 바꾸는지 표 아래 `.so-hint`로 적는다("체크한 2건은 ③ 저장 때 판매중으로 바뀌어요").
